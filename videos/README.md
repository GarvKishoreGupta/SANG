# Project demonstration video

Upload the SANG smart-home demonstration video into this folder.

1. Open this folder on GitHub.
2. Choose **Add file → Upload files**.
3. Select the video, preferably named `sang-demo.mp4`.
4. Commit the upload to `main`.

[Open the upload page](https://github.com/GarvKishoreGupta/SANG/upload/main/videos)

Suggested coverage: overview of the model, keypad door access, RFID garage, temperature/humidity and fan speed, MQ-2 buzzer, motion/darkness lighting, and telemetry/dashboard.

No video is included yet. After uploading, add a relative link to the actual filename here. If GitHub rejects the file because of its size, use a compressed copy or host it externally and add its viewing link here.
